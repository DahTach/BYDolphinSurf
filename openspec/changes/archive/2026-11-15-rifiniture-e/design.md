## Decisions

**D1 — In sintesi → Righe MD3 (variant A of `ui-drafts/e-rifiniture.html` Block 3A):** the 3 tonal tiles and the old `bg-surfLox` wrapper become ONE `bg-surfC rounded-[24px]` (clipped, `overflow-hidden`) card that contains, top to bottom: the "In sintesi" heading, three tappable list rows separated by INSET hairline elements (`h-px bg-white/[0.06] mx-4` — separate divider elements, NOT row borders, so the row's radius morph stays clean exactly as the mockup guards), and the footer line "Orizzonte 15 anni · 4,5k / 300k km · 1,5%" (live km segment) at the bottom behind one more inset hairline. Row anatomy: leading 40px circular icon container with status tonal fill (`bg-okC`/`bg-waC`/`bg-errC`) + 20px stroked glyph (`onOkC`/`onWaC`/`onErrC`: check / clock-alert / alert-triangle), text stack (label 15px `card-title`-weight `onSurf` "In regola"/"In scadenza"/"Scadute" + sub-line 11px `meta` `mut`), trailing count 22px (`title` role) `font-black` `onSurf` + 20px chevron `mut`. Rows are square inside the clipped card and morph ONLY their radius toward `rounded-[16px]` (250ms `--e-spring`, spring back on release) under the universal `scale(.97)` press layer — the tile press-scale exception and the `.press-tile` utility (`src/styles.scss:121,161`) are deleted; every element presses at `.97` (BLOCKER-1 ruling: the row morph is a radius morph only). Tap contract unchanged "as today": ripple + `/attivita?stato=` deep link fired 600ms after tap (reduced motion immediate), cancelled by a second activation or any other navigation, keyboard activation immediate; counts keep the count-up primitive.

**D2 — Sub-lines are static status glosses:** the 11px sub-lines are static, truthful Italian glosses of the status criterion (e.g. "interventi in tempo" / "in arrivo a breve" / "da registrare" — exact wording is the implementer's judgment). As static glosses they contain NO figures of any kind — never invented data derivations such as "entro 30 giorni", never counts or fractions. (The mockup's "entro 30 giorni" and "2 di 11 attività" demo strings are illustrative, NOT approved content.)

**D3 — One "Stato veicolo" card with the Onda M3E wave:** "Prontezza" + "Cicli LFP" collapse into ONE `bg-surfC rounded-[24px] p-5` card (eyebrow "STATO VEICOLO", `grid grid-cols-2 gap-4` cells — NOT stacked rows). Each cell: label 12px `label` `onSurfV`, display value 30px `font-black` `onSurf` + suffix 13px `mut` ("%" / "/5.000", `whitespace-nowrap` — the display line must not wrap), support line 11px `meta` `mut` ("2 di 11 in regola" / "≈ 0,3% vita utile"), and a wavy M3E progress below (D4). Values stay computed from the store (ND-3 unchanged). This supersedes the `refine-cruscotto-md3` "neutral 2-col stat cards" decision — recorded as resolved: ONE shared card, not two.

**D4 — Wavy progress primitive (design-system):** track and fill share ONE canonical sine-wave path copied verbatim from `ui-drafts/e2-stat-grid.html` variant B — `d="M2 6 Q9 -1 16 6 T30 6 … T198 6"` (midline y=6 from x=2 to x=198 so the round caps stay inside the `viewBox="0 0 200 12"`, first bump up, Q control points ±7 off-axis → true curve amplitude 3.5, half-period 14 → wavelength ≈28px) — stroked `fill: none`, `stroke-width 4`, round caps, rendered `width: 100%` / `height: 12px` (`h-3`) with the default `preserveAspectRatio` (uniform scaling, centered), exactly as the mockup renders. `pathLength="1000"` normalizes the length; the fill is carved with the `stroke-dasharray` PAIR `dash gap` = `P 1000` (never a bare dash length) where `P = value% × 10` (18% → `180 1000`). **Wave-head rules:** 0% renders EMPTY (no head); any value > 0 gets `P = max(value% × 10, 45)` — the floor is exactly 45/1000 (the 0,3% bar must read as a living wave head, never empty). Entrance animates `stroke-dasharray` from `"0 1000"` to `"P 1000"` over 650ms `--e-spring` on activation only; data edits transition `stroke-dasharray` over `--d-small` (250ms) `--e-emph` and never replay the entrance; reduced motion: final fill immediately. Track `surfHiX`; fills `prim` (Prontezza) / `onTerC` (Cicli). The user said "circular" progress but chose the Onda M3E wave over ring/thumb variants after review — rings were banned by `refine-cruscotto-md3`, and the wave supersedes the linear bar as THE progress anatomy (linear stays legal for other uses).

**D5 — FAB sheet fields per expected input length (`ui-drafts/e2-stat-grid.html` sheet block):** `grid grid-cols-2 gap-4` (constant 16px both axes) sized by expected input length — Attività `col-span-2` (select + chevron, long titles), row: Data + Chilometraggio (half/half), Luogo `col-span-2` (free text), row: Costo + Durata (half/half). Half-field fit rule: the value sits in a `flex-1 min-w-0` slot with the trailing suffix `shrink-0` (12px) so long values truncate and half columns never overflow at 430px (native date control included). Field anatomy unchanged (shared pill `app-text-field`, `h-14`). Footer buttons match the mockups: "Annulla" auto-width (`px-6`) + "Registra" filled `flex-1` (NIT-14 ruling — the equal-width pair is superseded); validation (ISO date + numeric km), save path and dialog semantics UNCHANGED. Full-width rows for free-text/long selects; half columns for dates, amounts, durations. The e2 sheet block supersedes `e-rifiniture` Block 2 (which predates the per-length ruling).

**D6 — Hero glow REMOVED:** delete the ambient glow element and its breathing animation entirely — no static glow fallback either. The hero keeps everything else from `m3e-morfosi`: status tint map, corner morph 48→32px, badge timeline, entrance. `shadow-hero` is the only depth cue. `--d-breathe` and the ambient-loop CSS exemption die with the glow (their only consumer) — the JS count-up easing exemption stays; code removals: the glow logic in `dashboard.ts`, the `.hero-glow` styles incl. their reduced-motion rule (`src/styles.scss:405`) and the `--d-breathe` token (`src/styles.scss:87`). Spec cleanup: the `m3e-morfosi` requirement "Hero ambient glow and entrance choreography" becomes "Hero entrance choreography"; every glow sentence/scenario that would be false afterward is removed or rewritten (including the "hero swap retints the container and glow" wording and the design-system reduced-motion "glow static .55" scenario).

## Risks / Trade-offs

- [Sub-lines drifting into fake data] → D2 makes the glosses static strings in the template; no figures of any kind allowed in sub-lines (scenario-asserted).
- [Tiny wavy fills rendering as nothing] → D4 wave-head rules (`0 1000` empty at 0%, `45 1000` floor above 0) with scenarios asserting the 0,3% mark and the 0% empty case.
- [Spec references to retired elements lingering] → this change performs the cleanup instead of deferring it: `design-system` "Interactive state layers" (sintesi rows, uniform `scale(.97)`), "Motion tokens and easing scale" (breathe token + ambient-loop exemption deleted), "Press shape morphs" (in-card row flavor), "Shape and type scale" (tile examples retired), the `vehicle-data`/`activities` cross-references, and the two sync-preserved Purpose lines (Sync note below).
