## Context

- v2 (`refine-cruscotto-md3`) shipped and archived; canonical specs live in `openspec/specs/`. The UI is M3-flavored but has no motion language, no reduced-motion handling, inconsistent press feedback (settings rows: none), radius/type drift across pages, hardcoded hexes, and a real bug: the hero `bg-waC` chip on the `bg-waC` "in scadenza" hero is invisible.
- Approved motion source: `ui-drafts/d2-morfosi.html` ("Morfosi"). Two cherry-picks from `ui-drafts/d3-vivace.html`: kinetic countdown badge (odometer digit roll) and scroll-aware header. Everything else in d3 (car stage, navbar labels, cinematic 24px/letter-spacing entrances) is explicitly not picked.
- Stack constraints (locked): Angular 22 standalone + signals, zoneless, TypeScript strict, Tailwind 4 (`@theme`), bun, no new dependencies (no Angular animations package, no CDK), no forms library. Reference code organization `~/Developer/AutofficinaPindemonte`.

## Goals / Non-Goals

**Goals:** give the app a real Material 3 Expressive motion + shape language per d2; make every interactive element respond to press/focus; fix the chip contrast bug with a durable rule; morph the FAB into its sheet; polish all pages consistently without touching content or data logic.

**Non-Goals:** car stage / floating car / parallax, navbar labels, letter-spacing or 24px cinematic entrances (d2 uses a 16px rise), theme toggle/light mode, new pages, icon library, data-model/seed/status-logic changes, content changes to Storico/Prodotti.

## Decisions

**D1 — Motion token foundation** (`src/styles.scss` `@theme`/`:root`): easings — `--e-emph: cubic-bezier(0.2,0,0,1)` (entrances, hovers — never opens), `--e-spring: cubic-bezier(0.34,1.4,0.64,1)` (≈3% overshoot: opens, radius morphs, badge, bars, nav indicator), `--e-exit: cubic-bezier(0.3,0,1,1)` (closes). Easing ownership: **open = 550ms `--e-spring`, close = 450ms `--e-exit`** — `--e-emph` never times an open. Named duration scale (`--d-*`): every used duration is a named token, no ad-hoc values — `--d-press` 140ms (press scale/state layers), `--d-small` 250ms (radius morphs, focus rings, active-button width), `--d-fade` 350ms (content fades), `--d-medium` 400ms (scrims, navbar-indicator travel, icon pop, settle tick, route transition), `--d-exit-flight` 450ms (every close/exit flight — including the morph close, which does NOT use the large band; also the navbar indicator's 450ms width flight), `--d-ripple` 500ms (ripple), the `large` band 550–650ms (`--d-large` 550ms morph open / entrance rises / badge spring; `--d-roll` 600ms digit rolls + hero corner morph; `--d-bar` 650ms bar fills), `--d-count-up` 700ms (count-ups), `--d-breathe` 6000ms (ambient loops). Delays are named too: entrance stagger 55ms (`--stagger`), sheet content fade delay 150ms (`--d-content-delay`). Documented exemptions from the CSS token rule: ambient loops may only use `--d-breathe`, and JS easing curves (count-up cubic ease-out) live in JS per D11. Animate `transform`/`opacity` (and the morph's geometry properties) only. Reduced motion: `@media (prefers-reduced-motion: reduce)` clamps all animation/transition durations+delays to `.01ms` and snaps `.enter`/hero elements to final state, plus a `matchMedia` JS gate for discrete steps (count-ups jump to target, no stagger delays, no stretch animation, ripple/navigations immediate, FAB close timeout 0). Single outcome everywhere: instant snap — no plain slide-up, no plain fade fallbacks. The hero glow stays visible at static opacity `.55`.

**D2 — State layers**: one `.press` utility (global SCSS or per-component mixin — same values everywhere): `::after` white overlay with `border-radius: inherit`, hover `opacity .06`, `:active .10` + `scale(.97)` at 140ms `--e-emph`; `:focus-visible` 2px `prim` outline, 2px offset. Applied to exactly this interactive set: navbar items, FAB, filled/text/icon buttons, category filter chips, the dismissible `stato` chip + its ×, sintesi tiles, queue rows, activity cards, settings-sheet rows, text fields (settings rows currently have zero feedback). Settings rows get a pill base radius (`rounded-full`) so their state layer/morph has a shape. History rows and product cards are NOT interactive → NO press feedback at all (matches `openspec/specs/history/spec.md` non-interactive rule). Every interactive control gets a ≥44px hit area (padding or pseudo-element; visible footprint can be smaller for chips/×). `-webkit-tap-highlight-color: transparent`.

**D3 — Shape & type scale**: radius scale — pill `rounded-full` (FAB, buttons, chips, fields, rows, nav), 20px tiles, 24px cards, 28px sheets/large panels, 32px hero; kill drift (e.g. `products.html` MAI box `rounded-2xl` → `rounded-[20px]`). Type scale as named roles covering every mandated size — no sizes outside these roles: `caption` 10px bold (two documented styles: eyebrow — uppercase, `tracking-[0.14em]`, `mut`; inline — normal case, inherits color), `meta` 11px, `label` 12px (hero label, hero badge, card labels, field suffix), `body-sm` 13px, `body` 14px + `text-button` 14px (M3 label-large — e.g. "Annulla"), `button-large` 15px + `card-title` 15px (filled buttons, card titles), `field` 16px, `title` 22px, `display` 26–30px `font-black` (tile counts 26px, stat values 30px). One caption role (two documented styles per D3); one spacing rhythm: page blocks 24px (`space-y-6`), eyebrow→content 16px (`space-y-4`), sheet inner padding 20px (`px-5`) — no ad-hoc gaps.

**D4 — FAB: press morph + FAB→sheet morph** (d2 technique). Press morph: while `:active` the circle eases to a squircle (`border-radius` ~30% → spring back, 250ms `--e-spring`) under the standard `scale(.97)`. Morph: a single absolutely-positioned container starts at the FAB's exact circle geometry (`bg-primC`, 56px, `bottom-24`, right gutter `max(1rem, calc(50% - 199px))`) and transitions `left/right/bottom/height/border-radius/background-color/box-shadow` to the full sheet (`rounded-t-[28px] bg-surfC shadow-sheet`, full-bleed within the 430px frame) over 550ms `--e-spring`; `overflow: hidden` makes it a window whose inner form is pinned to its **final** screen position (compensating `translateX`), so the expanding window reveals planted content; the `+` icon rotates 90°/scales .6 out; content fades in 350ms `--e-emph` +150ms delay; scrim `bg-black/70` fades 400ms. **Angular survival**: the overlay is kept *mounted* (`@if` only around overlay visibility is forbidden — instead render the overlay container always and toggle `.open`/`visibility` classes; or gate with a signal that keeps DOM alive through the exit). Measurable exit rule: after close begins the overlay becomes inert immediately (`pointer-events: none`, keyboard-unreachable) and stays mounted ≥450ms (`--d-exit-flight`) before unmount. Real FAB hides (`opacity 0, scale .8`) while the morph is open. Close reverses geometry with 450ms `--e-exit`. Dialog a11y: `role="dialog"` + `aria-modal="true"`, focus into the sheet on open, Tab focus trap, Escape closes, focus restored to the FAB on close. Reduced motion: no morph — the sheet snaps open and closed instantly. Escape/backdrop/cancel/save close.

**D5 — Navbar fluid indicator**: the sliding/morphing indicator IS the single `bg-primC` pill — navbar buttons carry NO background fill. The pill translates via `--x` (400ms `--e-spring`) while a width keyframe stretches it to `max(from,to)+18px` at 55% of the 450ms `--e-emph` flight and settles to the item's width; the active button only widens 48→52px (250ms `--d-small`) and flips its icon color to `onPrimC` (inactive: `w-12`, `mut` icons); active icon pops 1→1.15→1 (400ms spring, peak 45%). Resize re-places without animation. No labels.

**D6 — Hero (dashboard)**: ambient glow — sibling behind the hero, `inset: -6px`, radial/status-tinted fill (status `err`/`wa`/`prim` color), `filter: blur(70px)`, breathing `scale 1→1.06 / opacity .45→.7` `--d-breathe` (6000ms) ease-in-out infinite (err tint when scaduto). Hero container corner morph 48→32px over 600ms (`--d-roll`) `--e-emph` on entrance. Entrance timeline from route/pane activation (T0): the hero block's entrance rise ("car entrance") runs 0–550ms; the badge pop starts at T+750ms (badgeSpring 550ms `--e-spring`, scale .6→1.03→1) — full timeline in D7. Entrance rise+fade is shared with the glow via the `.enter` wrapper. Reduced motion: glow static at `.55`, no corner morph, badge appears with the card. Data-driven hero swap retints container + glow and snaps the badge text (D11).

**D7 — Kinetic countdown badge (d3)**: rendered text is ALWAYS unpadded — "+N g" / "tra N g" / "oggi", never "+04". Digit cells derive from the current rendered text (variable count: "+4 g" = 1 cell, "+230 g" = 3 cells): each digit is a masked strip — `height/line-height: 1.15em`, `overflow: hidden` window, strip of 0–9 twice, `translateY(-(10+value)·1.15em)` over 600ms `--e-spring`, 55ms stagger per digit; then a settle tick (`scale 1→1.08→1`, 400ms spring) on a **nested inner span** so the tick transform never clobbers the pop transform. Masked strips roll only on page/route activation; "oggi" has no digit cells (pop + tick only); mid-session value changes (hero swap after "Registra ora") SNAP to the new text without roll. Absolute timeline from activation (T0; the d3 +460/+540 relative timeline is dropped): hero/car entrance rise 0–550ms ("car entrance" = the hero block's entrance rise); badge pop T+750ms (550ms spring); digit strips roll T+800ms (55ms stagger, 600ms each); settle tick ≈80ms after the last digit cell settles (last cell settles T+800+(n−1)×55+600ms). Placement stays `-top-1 right-2` on the car (accepted deviation from d2's `-top-2 right-1`). Reduced motion: no roll (strips set to target), no tick.

**D8 — Scroll-aware header (d3)**: the header SHALL be `sticky top-0` within the 430px frame, with the `surf/80 backdrop-blur` condensation bar. The app scrolls on **window** (not an inner container) — a passive scroll listener throttled with `requestAnimationFrame`, computing `p = clamp(scrollY/96, 0, 1)` and writing one custom property `--cond` (3 decimals) on the frame; CSS `calc()` fans it out: avatar `scale(1 - 0.15p)`, title `scale(1 - 0.05p) translateX(2p px)` (`origin-left`), spec chip `opacity (1 - 0.35p)`, `surf/80 backdrop-blur-xl` bar `opacity: p`. No transitions on interpolated props (cursor-locked, fully reversible). Route change scrolls to the top of the frame (`scrollPositionRestoration: 'enabled'` in the router config, or equivalent); fragment jump (`#veicolo`) keeps the native anchor behavior and the condensation follows the resulting scroll position. Cleanup: remove the listener + cancel the rAF on destroy. Reduced motion: instant swap at the 96px threshold (decided — no hedge).

**D9 — Press shape morphs**: rows (`rounded-full` → 22px: queue rows, settings rows) and cards (24px → 16px: activity cards) morph radius at 250ms `--e-spring` while the shared press layer handles `scale(.97)` at 140ms — two speeds on one element (d2). Spring back on release. Non-interactive rows/cards (history rows, product cards) morph nothing (D2).

**D10 — Sintesi tile ripple**: tap → `scale(.95)` + a 12px center-origin ripple ring (2px `white/35` border + radial white/18→0 fill) scaling to 14× and fading over 500ms `--e-emph`, removed after 600ms; navigation to `/attivita?stato=...` fires 600ms after tap — the 500ms ripple fade must complete first (0ms reduced motion); a second tile activation or any other navigation cancels the pending navigation; keyboard activation (Enter/Space) navigates immediately with no delay.

**D11 — Entrances & data animation**: `.enter` blocks rise 16px + fade (550ms `--e-emph`) with 55ms stagger on route/pane activation only; count-ups (`--d-count-up` 700ms, JS cubic ease-out — the documented JS easing exemption of D1) for sintesi counts and stat numbers; bars fill 0→width with 650ms `--e-spring`. Triggered from the router/pane-activation hook, never from raw change detection. Data-change behavior (one clause across the animation requirements): data edits update values, bar widths and tints with the existing width/color transitions but NEVER replay entrances, count-ups, digit rolls; hero swap retints container + glow and snaps the badge text. Angular: toggle `.in` classes via an activation signal/effect; force-restart with reflow or class remove + microtask re-add. App-level route transition (app-shell): the incoming routed page slides +12px → 0 with fade (400ms `--e-emph`); the outgoing page swaps immediately (the router destroys it — no exit transition), a deliberate simplification over the draft's pane-out animation.

**D12 — Sheet motion**: settings sheet + FAB sheet slide `translateY(100%) → 0`, open 550ms `--e-spring` / close 450ms `--e-exit`, scrim 400ms `--e-emph`, drag handle (`w-9 h-1 rounded-full bg-outline`) decorative, safe-area bottom padding. Same mounted-until-exit rule as D4 (overlay inert during the exit, mounted ≥450ms). Dialog a11y on both sheets (D4 wording): `role="dialog"` + `aria-modal="true"`, focus into the sheet on open, Tab focus trap, Escape closes, focus restored to the trigger (FAB / gear) on close. Reduced motion: open/close instantly.

**D13 — Status chip/badge redesign + contrast fix**: one `status-chip` component, one `variant × status` color map — `variant: 'card' | 'hero' | 'badge'` (the badge variant owns the digit-strip DOM); "one markup" wording retired in favor of "one component, one color map". Map: `card` (on `surfC` cards, tonal) — ok `bg-okC text-onOkC`, in-scadenza `bg-waC text-onWaC`, scaduto `bg-errC text-onErrC`; `hero` + `badge` (on the tinted hero container) — ok `bg-onOkC text-okC`, in-scadenza `bg-onWaC text-waC`, scaduto `bg-err text-onErr`. **≥3:1 fill-contrast rule against the container.** This fixes the invisible `bg-waC`-on-`bg-waC` chip (and the identically-colored badge) and the `bg-prim`-on-`primC` ok badge without introducing new colors (token set is locked apart from the car-art extension below).

**D14 — Buttons/fields/empty states/tokens**: buttons — filled full-width (`rounded-full h-12`, `button-large` 15px bold; CTAs and sheet submits) and filled compact (`rounded-full h-9 px-4`, `text-button` 14px bold; card "Registra"), text (no border, `text-button` 14px = M3 label-large, e.g. "Annulla"), icon (40px circle) all with D2 layers + press morph; text-field keeps the pill anatomy but gains the d2 focus motion (ring scales in from 1.06, 250ms `--e-spring`; label color 250ms) and native `<select>` renders dark via `color-scheme: dark` (no dropdown lib); empty states — filtered-to-zero Attività shows a friendly Italian empty state with a "Cancella filtro" action, hero/queue hidden states render graceful captions. Token hygiene: literal `#hex`/`rgba()` colors are banned in `src/` EXCEPT (a) token definitions in `styles.scss` `@theme`/`:root`, (b) Tailwind built-in `black`/`white` used with alpha as overlays/state layers (`bg-white/[0.06]`, `bg-black/70`), (c) derived-alpha vars of existing tokens, (d) the `theme-color` meta value in `index.html` (equal to `surf`). Cleanup targets: car SVG `#b96357/#c96f60/#55291d/#3e1d1c` in `pages/dashboard/dashboard.ts`, wheel `#2c130c` in `pages/dashboard/dashboard.html:39-40`, body `#000000`/`#eae4e2` and `::selection` `rgba(227,168,155,0.3)` in `src/styles.scss:58-66` (the selection color becomes a derived-alpha var of `prim`), frame `bg-black` in `src/app/app.html:2` (→ `bg-surf`). Car-art tokens `carBody`/`carBodyErr`, `carAccent`/`carAccentErr` and `carWheel` (the exact hexes above) are declared in `styles.scss` alongside the palette — the one documented token-set extension (app-shell delta); the palette is otherwise locked. And **delete** the empty `src/app/app.scss` together with its `styleUrl` reference in `app.ts` (global styles stay in `styles.scss`) — resolved: delete, not "use it".

**D15 — Consistency sweep**: one press-feedback value set (kill `scale-95/0.98/0.99/0.97` drift → tiles .95, everything else .97), one spacing rhythm (24/16/20px per D3), one caption system (D3).

## Risks / Trade-offs

- [Morph DOM torn down by `@if`/`@for` mid-transition] → keep overlay mounted and toggle `.open`/`visibility` classes; after close begins the overlay is `pointer-events: none` and stays mounted ≥450ms (`--d-exit-flight`); zones/`ChangeDetectorRef` untouched.
- [Scroll listener cost] → single rAF-throttled passive listener writing one custom property; removed on destroy.
- [Count-ups/entrances re-firing on every CD cycle] → activation-only triggers (router activation/pane signal), never computed-driven.
- [Chip contrast permutations] → one `variant × status` map in the chip component; the ≥3:1 rule is testable per scenario.
- [Reduced-motion paths diverge] → one CSS kill-switch + one JS `matchMedia` gate; single outcome everywhere = instant snap (no slide-up/fade fallbacks); all specs carry reduced-motion scenarios.
