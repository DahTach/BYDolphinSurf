## Accepted deviations vs `ui-drafts/d2-morfosi.html`

- Badge position is `-top-1 right-2` per spec (the d2 draft uses `-top-2 right-1`).
- Route transitions are incoming-only (slide +12px → 0 + fade): the outgoing page is destroyed by the router, so there is no pane-out animation.
- Badge timeline is the absolute one of `specs/dashboard` (pop T+750ms / rolls T+800ms / tick ≈80ms after the last digit cell settles from activation) instead of the drafts' relative timings (d3's +460/+540 dropped).
- Hero glow for `in-scadenza` tints with `onWaC` (the locked palette has no bright `wa` token and `waC` equals the container fill); `scaduto` → `err`, `ok` → `prim`.
